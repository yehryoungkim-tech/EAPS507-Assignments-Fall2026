# Assignments for EAPS 507 – Fall 2026

## Overview

This repository contains my completed Python assignments for EAPS 507 during Fall 2026. The assignments cover Python fundamentals, numerical calculations, data manipulation with Pandas, and multidimensional data analysis with Xarray.

The purpose of this repository is to organize my coursework, track changes, and support scientific reproducibility.

## Assignment List

### 1. Madhava Pi Calculation
**File:** `01b_madhava_pi_calculation-4.ipynb`

This assignment uses the Madhava-Leibniz series to approximate the value of pi. It includes calculating errors, visualizing convergence, and using Python functions.

### 2. Python Refresher
**File:** `02_last_class_refresher(1).ipynb`

This assignment reviews Python fundamentals, including functions, recursion, factorial calculations, and variable scope.

### 3. Pandas Data Manipulation Tutorial
**File:** `EAPS507_Pandas_Data_Manipulation_InClass_Tutorial(2).ipynb`

This tutorial introduces data manipulation using Pandas. It covers reading datasets, filtering data, handling missing values, grouping records, and performing calculations.

### 4. Xarray Beginner Tutorial
**File:** `Xarray_10_Minute_Beginner_Tutorial(1).ipynb`

This tutorial introduces Xarray for working with multidimensional data. It covers DataArrays, Datasets, coordinate-based selection, basic calculations, and data visualization.

## How to Run the Notebooks

1. Open or download a Jupyter Notebook (`.ipynb`) file from this repository.
2. Open the notebook using Jupyter Notebook, JupyterLab, or Google Colab.
3. Install the required Python libraries, such as NumPy, Pandas, Matplotlib, and Xarray.
4. Run the code cells in order.

**Note:** The Pandas tutorial requires the external data file `IN_Features_20140204.txt`. Some tutorial exercises may also contain incomplete starter code.
